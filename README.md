# swot_airsea_eddy_analysis
Accompanying analysis of SWOT observations of wind-wave-current interactions over mesoscale eddy. This repository contains two main directories:

- **`preprocess/`**  
  Utility functions for pre-processing SWOT and supplemental datasets  
    -- **`tag_eddy.m`**  
    -- **`load_vars_into_memory_universal.m`**  
    -- **`load_and_grid_eddy_universal.m`**  

- **`fig_code/`**  
  Code for generating the figures in publication.
